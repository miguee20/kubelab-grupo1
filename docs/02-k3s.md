# 02 · Kubernetes installation (k3s)

## Why k3s (INF-04)

| Criterion | k3s | kubeadm | RKE2 |
|---|---|---|---|
| Control plane RAM | ~500 MB | ~1.5 GB (separate etcd, apiserver, controller and scheduler) | ~1.2 GB |
| Installation | One binary, one command per node | Several packages; runtime and CNI installed separately | Similar to k3s, but heavier |
| Datastore | SQLite (kine), enough for a single control plane | etcd | etcd |
| Certification | CNCF-certified distribution | — | Certified |

With 6 GB of physical RAM and 4 VMs of ~1 GB each, k3s is the only option that leaves memory for the applications, observability and Argo CD. It is standard Kubernetes: same objects, kubectl and CRDs.

## Installation

In the `pve` shell:

```bash
curl -fsSL https://raw.githubusercontent.com/miguee20/kubelab-grupo1/main/scripts/proxmox/03-install-k3s.sh -o 03.sh && bash 03.sh
```

[`03-install-k3s.sh`](../scripts/proxmox/03-install-k3s.sh) installs the server on `k3s-cp` and joins the 3 workers with the server token. It also installs `kubectl` on the `pve` host. Installed version: **v1.36.5+k3s1** (stable channel).

### Relevant flags

| Flag | Reason |
|---|---|
| `--disable traefik,servicelb` | Traefik and MetalLB are installed by Argo CD from `k8s/platform` (NET-01, NET-02) |
| `--disable local-storage` | The default StorageClass is NFS (PER-01) |
| `--disable metrics-server` | Installed by Argo CD (HA-04), so it is versioned in the repo |
| `--node-taint node-role.kubernetes.io/control-plane=true:NoSchedule` | The control plane does not run application workloads (INF-05) |
| `--disable-cloud-controller`, `--disable-helm-controller`, `--disable-network-policy` | Not used in a bare-metal lab without Helm CRDs or NetworkPolicies; frees control plane memory |
| `GOGC=50` (k3s service environment) | The Go garbage collector returns memory sooner, lowering peak RAM |
| `system-reserved` and `eviction-hard` | Reserve memory for the OS and evict pods before the node runs out of RAM |

The `worker` role label is applied with `kubectl` after the nodes join, because the kubelet's NodeRestriction admission forbids self-assigning `node-role.*` labels.
